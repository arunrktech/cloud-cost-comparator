# Cloud Cost Comparator

A Claude skill that compares AWS, Google Cloud and Azure for a project.

Give it an HLD, a requirements document or discovery session notes, and it produces a Word report with:

* the equivalent architecture on each cloud, with a diagram (PNG and editable draw.io)
* a priced bill of materials per cloud, using official vendor prices
* the cost variance between the three clouds, per component and in total, on demand and with 1 year commitments
* a one page infographic of each cloud's positives and negatives for the project
* every assumption and every price source, so each number can be checked
